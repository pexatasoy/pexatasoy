<p><b>How it runs.</b> One server: Caddy in front, every product as its own process, PostgreSQL behind. Web apps in Next.js and TypeScript, phone apps in Swift and Kotlin, desktop tools in Rust, games in Pixi and Godot. iOS builds go through GitHub Actions on macOS straight to TestFlight.</p>

<p><sub>Most of the code lives in private repositories. Happy to walk you through any of it.</sub></p>
